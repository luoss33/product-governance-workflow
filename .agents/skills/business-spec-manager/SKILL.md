# 业务事实治理

[治理协议](<../../../00、工作台/治理协议.md>)是事实确认与同步契约。按任务读相关章节。

| 当前动作 | 读协议章节 | 预期结果 |
| --- | --- | --- |
| 收到新的业务输入 | [事实链和状态](<../../../00、工作台/治理协议.md#事实链和状态>)、[采集与对齐](<../../../00、工作台/治理协议.md#采集与对齐>) | 原话与证据位置、与现行规则的差异、尚待裁决事项 |
| 准备确认 | [确认](<../../../00、工作台/治理协议.md#确认>) | 可独立判断的完整规则文本、影响和适用范围 |
| 收到明确回复 | [固化](<../../../00、工作台/治理协议.md#固化>) | 决策、规则及替代关系、唯一现行规范、资产影响 |
| 检查落点 | [资产同步与交付](<../../../00、工作台/治理协议.md#资产同步与交付>) | 授权范围内的实际修改、对应验证和同步记录 |

从[当前状态](<../../../00、工作台/当前状态.md>)定位规范；根据差异定向读取决策和原始资料。会议意见、AI 草稿、资产现状和测试用于理解或验证。以明确人工确认决定候选规则是否生效。

确认回复新增限定或例外时，回到比较和对齐。证据有冲突、已有主题的规范缺失或无法唯一定位时，暂停受影响的规则写入，并说明需要核对的材料。首个规则已确认时方可新建主题现行规范。

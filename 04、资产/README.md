# 资产

保存流程方案、页面方案、原型、需求文档和其他业务交付物。资产应表达当前规范中的规则；它们不能反向证明业务事实。

- 只按已确认规则制作业务资产。发现新业务含义时返回变化对比和用户确认。
- 使用 [流程方案模板](../00、工作台/模板/流程方案.md) 或 [页面方案模板](../00、工作台/模板/页面方案.md) 建立评审方案。
- 对需要追踪同步状态的资产，在 [当前资产](../00、工作台/当前资产.md) 登记。
- 使用 [资产说明模板](../00、工作台/模板/资产说明.md) 记录规则映射、交付状态和验证摘要。
- 用户锁定的内容按明确的资产和授权范围处理。

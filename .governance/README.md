# 本地结构检查

从工作区根目录运行：

```text
node .governance/check.mjs
node --test ".governance/tests/*.test.mjs"
```

检查器只读取本地文件，不需要安装依赖或连接网络。可用 `--root <目录>` 检查另一个工作区。

检查内容包括七个治理目录、规则与技能入口、四张登记表的表头、当前规范的唯一登记，以及关键文件和登记中 Markdown 本地链接是否存在。检查器会处理中文路径、百分号编码和尖括号包裹的空格路径。

它只验证文件结构和链接关系，不判断业务规则是否正确、用户是否完成确认或交付是否验收。用户可以不运行此检查器，直接按工作指南使用目录和模板。
